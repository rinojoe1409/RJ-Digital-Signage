# 004 — Persiapan source dan manual publik

Tanggal: 11 November 2026.

Pengguna mengizinkan aplikasi dan manual tersedia publik. Export mandiri menyalin hanya berkas tracked dari source acuan, tanpa riwayat Git, data, token, cache, backup, binary atau hasil build. Target: https://github.com/rinojoe1409/RJ-Digital-Signage.

- CMS tetap 0.2.4; Player tetap 0.3.2. Durasi unlimited yang ditunda tidak dibawa.
- Manual 1.1 mengarahkan pengunduhan ZIP publik tanpa login dan memakai USER-LINUX sebagai contoh akun.
- Preset alamat nyata pada launcher/installer/panduan diganti IP-SERVER. Form player tetap meminta alamat CMS yang benar sebelum pairing.
- README menjelaskan CMS siap dijalankan melalui Docker dan source build EXE disertakan, sementara binary installer publik disiapkan untuk [GitHub Releases](https://github.com/rinojoe1409/RJ-Digital-Signage/releases). Build tersebut membawa branding/alamat generik tanpa menaikkan versi CMS 0.2.4 / Player 0.3.2.

- Tidak ada perubahan pada repository asal atau server. Source ini baru tahap persiapan; catat hasil pemeriksaan dan push setelah selesai.
