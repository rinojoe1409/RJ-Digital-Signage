# Manual instalasi RJ Digital Signage

Manual instalasi adalah buku petunjuk pemasangan: menyiapkan Linux dan Docker, menjalankan CMS, membuat admin, lalu menghubungkan player Windows. Source aplikasi tersedia di repository ini dan installer player tersedia pada halaman Releases.

Buka [manual lengkap instalasi server Linux dan player Windows](deploy/Manual-Instalasi-RJ-Digital-Signage-Server-Linux.md). Dokumen lengkap berada di deploy/ agar turut disertakan dalam paket source hasil build.
